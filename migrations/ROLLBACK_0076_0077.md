# Rollback migrations 0076–0077

These migrations add one read-only inventory RPC and do not mutate tenant
business data. Roll back the frontend first if exports must be paused.

To disable the database surface without losing data, revoke `EXECUTE` on
`public.rpc_my_backup_inventory()` from `authenticated`. Dropping the function
is unnecessary. Restore testing must still target a new, empty staging project;
never restore a dump over the running staging or production database.
